# 相机布局与取景自测（2026-10-09）

本批为软件接入，未执行 Gradle、Android 测试或 APK 任务，编译与真机结果由用户填写。

## 操作与边界

- 默认 CameraX 普通相机；独立圆形快门保存原图，重复点击底部“拍摄”不拍照。拍摄横竖屏使用沉浸式全屏，隐藏底部导航／状态栏／系统导航栏；边缘滑动可临时唤出系统栏。
- 顶部左侧返回按钮退出到进入前的首页／我的（直接进入默认首页），旁边切换 3:4／9:16（横屏 4:3／16:9），右侧模型设置／拍照设置。比例、角色、外观、要求和脸部示范开关存入本地拍照偏好；AR 开关不持久化，每次新页面会话默认普通模式。
- 主界面为黑底白控件，操作由底部向上排列；预览尺寸只由屏幕、方向与所选比例决定，卡片、进度和弹窗不改变视口。三张构图等宽常显，应用后仍可点击卡片返回方案页。动作、表情、大小、说明、导演修改和备用换背景在构图详情内；人物、外观、要求、样片和 Debug 测试图片在拍照设置内。
- 普通相机快捷档位在实际 ZoomState 范围内取 1×、2×、3×、5×；最小倍率小于 1× 时追加该值。双指覆盖完整设备范围，每个显示帧最多提交一次，倍率变化不重绑相机。倍率读数来自 ZoomState 回传。当前后置相机不提供的厂商专属镜头档位不会伪造出来。
- 扫描、分析、生成和保存时锁定取景比例、倍率和模式；生成期间取消、重新扫描仍可直接操作。比例／变焦／模式改变会解除当前参考和背景确认，保留生成结果；重新开始扫描／单图生成仍走现有取消与串行交接。
- 拍照设置中主动开启 AR 后，等待 CameraX CLOSED，再启动 ARCore SharedCamera；退出／失败等待 AR 相机关闭才启动 CameraX。AR 固定 1×，禁双指变焦，退出恢复进入前倍率。需要重新应用符合 AR 相机条件的构图并确认背景／地面，不能直接复用旧世界坐标。
- CameraX 的预览、分析、冻结与照片使用同一 ViewPort；AR 原始 JPEG 转正后按拍摄时视口中心裁切，不合成人偶。任意比例的 Debug 导入图与方案预览等比显示。
- 拍照设置的角色／外观用于下一次生成，不修改现有方案；现有方案的手动调整和导演修改仍使用自身角色进行校验。

## 沉浸式退出与恢复

- 普通页面固定浅色白底黑字，保留强调色。拍摄状态不预留隐藏的底部 Tab 或状态栏高度，按钮避开显示刘海和系统强制手势区；3:4／9:16 仍等比适配，黑底铺满屏幕，不将相机画面拉伸到手机长宽比。
- 返回目标使用保存状态，旋转后保留；App 导航统一管理系统栏显隐、图标颜色和导航栏背景，在生命周期恢复或窗口重新获焦时重新应用。拍摄模块不独立修改或恢复系统栏。
- 左上返回可退出扫描／生成并复用现有取消和相机释放；保存照片时禁用退出，系统返回也拦截。系统返回先交给弹窗，其余阶段取消流程／返回实时页，LIVE 再返回退出。离开后的扫描资源与已有方案沿用现有保留策略，不重复初始化离线模型。
