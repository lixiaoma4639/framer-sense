## 构图卡片与详情原位转正（2026-10-19）

按用户确认，卡片编号及详情文字／控件跟随当前手机方向转正，照片和人像继续保持拍摄时方向。三张卡片分别在原区域内转动内容，保留卡片外框、排列及点击区域；详情只转动原面板内的内容，主预览、快门及底部操作位置不变，沿用 300ms 动画。

- 横向构图生成后，手机转向四方向：三张卡片、详情外框和快门保持原位，编号与详情文字／控件转正；照片与人像不能叠加旋转或拉伸。
- 每个方向点击三张卡片和“应用构图”，命中及选中方案正确；详情滚动方向随内容转正，松手不反向回顶。
- 输入导演修改要求、调整大小后旋转，保持草稿与当前方案；收起／展开构图选择及已有设置弹窗照常工作。

## 照片与人像方向第3步（2026-10-19）

每帧记录自己的四档拍摄方向，先按固定预览视口裁切，再转正照片像素；模型选景／构图与人像渲染共用选中照片的转正坐标。按用户选择，结果映回拍摄时的固定取景方向，之后转手机不会带动结果照片或人像转向；实时预览、页面布局和前两步控件／弹窗交互沿用原效果。

- 分别从横屏、竖屏进入相机，选 3:4 和 9:16，各自进行竖→左横→倒竖→右横→竖混合扫描。扫描会话、累计帧、倍率不重置，预览不重绑或黑屏。
- 自动选景后检查三张构图：背景方向与所选扫描帧一致，人像沿照片纵轴站立，不能侧倒 90°；生成等待中转手机，最终结果仍沿用选中帧的拍摄方向。
- 主动更换为不同方向的扫描照片，确认背景、三份构图及透明人像共同更新，不能混用上一个方向的渲染缓存。
- 结果出现后再转手机，照片和人像保持拍摄时方向，等比显示；向画面左右拖动人像，在两个横屏和倒竖屏结果上确认移动方向及幅度正确。
- 应用参考后，参考背景和透明人像使用同一方向；握持方向改变清除旧背景确认，迟到的旧方向匹配结果不能覆盖当前状态。AR 的落点与照片脚底一致，空间会话不因四档方向变化重建。
- 快门保存分别覆盖四方向和两种比例；在系统相册确认照片转正且裁切与预览一致。按下快门后立即转手机，保存方向仍取自快门请求开始时。普通 CameraX 只更新 EXIF，保留原 JPEG 保存；AR 按拍照开始时的方向及比例保存。
- 系统导入带旋转／镜像 EXIF 的照片，沿用导入图自身方向；转手机不改变其模型输入和构图结果。

## 操作与边界

- 默认 CameraX 普通相机；独立圆形快门保存原图，重复点击底部“拍摄”不拍照。拍摄横竖屏使用沉浸式全屏，隐藏底部导航／状态栏／系统导航栏；边缘滑动可临时唤出系统栏。
- 顶部左侧返回按钮退出到进入前的首页／我的（直接进入默认首页），旁边切换 3:4／9:16（横屏 4:3／16:9），右侧模型设置／拍照设置。比例、角色、外观、要求和脸部示范开关存入本地拍照偏好；AR 开关不持久化，每次新页面会话默认普通模式。
- 顶部金色“AI 构图”入口展开带淡入／收缩动画的要求输入栏，覆盖预览而不改变取景区尺寸。草稿走相机 MVI，确认后才保存到现有拍摄要求，供下一次扫描选景／构图使用；图标、顶部返回或系统返回可收起并放弃草稿，原方案不自动重新生成。编辑期间锁定拍照、变焦与开始扫描／生成，后台自动加载延后；忙碌期间禁用入口。拍照设置不再展示拍摄要求输入框，预览页的顶部入口用于编辑拍摄要求。
- 点击面板外的相机区域收起编辑区，点击不穿透到底层控件；原生键盘与面板内操作不会触发外部关闭。打开编辑器及选择文字时光标置于末尾。输入框下方按“历史记录、推荐指导”展示可滚动列表；用户文字确认后同文去重置顶，历史选用后确认也置顶，直接确认推荐句不记历史，编辑推荐句后按用户输入处理。历史末尾可逐条删除，删除不改变当前输入；历史和已采用文字的推荐来源标记复用模块 `SettingsStore`／SharedPreferences JSON 持久化，正常重启后恢复，无需新增 Room 或公共模块依赖。
- 主界面为黑底白控件，操作由底部向上排列；预览尺寸只由屏幕、方向与所选比例决定，卡片、进度和弹窗不改变视口。三张构图等宽常显，应用后仍可点击卡片返回方案页。动作、表情、大小、说明、导演修改和备用换背景在构图详情内；人物、外观、要求、样片和 Debug 测试图片在拍照设置内。
- 普通相机快捷按钮为 1×、2×、3×及 ZoomState 返回的设备最大倍率，过滤越界档位并去重；例如范围 1×～8×显示 1×／2×／3×／8×，范围 1×～2×只显示 1×／2×。默认 1×，选中态来自 ZoomState 回传；双指仍覆盖完整设备范围，每个显示帧最多提交一次，倍率变化不重绑相机。按钮是变焦快捷档位，不代表独立光学镜头；CameraX／Camera2 公开镜头参数保留为诊断信息，不参与按钮生成。`VlmCameraZoom` 的“最终倍率按钮”日志用于核对设备范围和按钮列表。
- 扫描、分析、生成和保存时锁定取景比例、倍率和模式；生成期间取消、重新扫描仍可直接操作。比例／变焦／模式改变会解除当前参考和背景确认，保留生成结果；重新开始扫描／单图生成仍走现有取消与串行交接。
- 拍照设置中主动开启 AR 后，等待 CameraX CLOSED，再启动 ARCore SharedCamera；退出／失败等待 AR 相机关闭才启动 CameraX。AR 固定 1×，禁双指变焦，退出恢复进入前倍率。需要重新应用符合 AR 相机条件的构图并确认背景／地面，不能直接复用旧世界坐标。
- CameraX 的预览、分析、冻结与照片使用同一 ViewPort；AR 原始 JPEG 转正后按拍摄时视口中心裁切，不合成人偶。任意比例的 Debug 导入图与方案预览等比显示。
- 拍照设置的角色／外观用于下一次生成，不修改现有方案；现有方案的手动调整和导演修改仍使用自身角色进行校验。

## 沉浸式退出与恢复

- 普通页面固定浅色白底黑字，保留强调色。拍摄状态不预留隐藏的底部 Tab 或状态栏高度，按钮避开显示刘海和系统强制手势区；3:4／9:16 仍等比适配，黑底铺满屏幕，不将相机画面拉伸到手机长宽比。
- 返回目标使用保存状态，旋转后保留；App 导航统一管理系统栏显隐、图标颜色和导航栏背景，在生命周期恢复或窗口重新获焦时重新应用。拍摄模块不独立修改或恢复系统栏。
- 左上返回可退出扫描／生成并复用现有取消和相机释放；保存照片时禁用退出，系统返回也拦截。系统返回先交给弹窗，其余阶段取消流程／返回实时页，LIVE 再返回退出。离开后的扫描资源与已有方案沿用现有保留策略，不重复初始化离线模型。
