# VLM 摄影决策 v3

## 优先级与交付状态

第一任务是环境构图的摄影美感：主体、层次、留白、引导线、色彩/明暗组织与干扰控制。第二任务是人物站位、姿势与背景协调：轮廓分离、不遮挡主体、不让背景线条穿过头部。表情、比例和 AR 为这两项服务。普通场景仍提供最佳可用三方案，说明不足；不将模型编号分数或构建结果作为摄影质量证明。

- 摄影决策软件接入：完成；未构建或执行自动化测试。
- 摄影视觉验收：待用户验收。
- 素材：保留现有角色和自然站立/侧身/回眸初稿；不增加素材，不推荐扶腰/步行停顿，不声明专业素材审核完成。

## 数据与执行

自动选景保留离线四帧、云端八帧。请求提供用户要求、角色身高、扫描绑定、实际倍率/相机能力及经过本地验证的动作和表情目录。三方案由模型分别组织，不固定景别组合。

`PhotographyDecision`：`version=3/imageId/sceneDescription/plans`。每项：`id/title/shot/crop/cropReason/head/foot/personRegion/actionId/expression/expressionIntensity/yaw/reason/guidance/backgroundKeepRegions/references/uncertainties`。坐标属于转正后的选中照片，完整人体区域 y 可在 -2..4，半身/特写脚底可在画面外。模型不能指定文件或骨骼矩阵。

参照物：`objectName/region/heightMinMeters/heightMaxMeters/depthRelation/evidence`。只有 SAME 才比较投影身高比例，其余前后关系记录未知；尺寸均为估计，不当作空间测量。参照一致性用于观察，不强行替换模型布局。

离线主路径一次单图紧凑摄影分析，生成上限640 tokens；替代编号排序与单独环境描述。提示词只列动作编号与支持表情，不传完整骨骼说明、AR 矩阵或上轮长输出。离线最多调用一次，不自动再次推理纠正；模型未完成、格式/资源/几何校验失败均报告失败，不补造方案、不展示临时参考。只有完整且有效的模型结果才进入预览。云端保留原有两轮及有限布局降级规则。正常换行与标点保留，只删除描述空行，不截断展示。编号入口保留兼容，原生推理仍串行、安全取消，离线无计费预算。

离线摄影分析使用长边不超过384像素的临时 JPEG，保持原画幅，通过 MNN 官方 `<hw>` 标签明确指定视觉编码尺寸，避免只缩小文件却仍使用旧的大尺寸计算图。普通推理/四帧选景每次恢复模型配置中的视觉尺寸，避免单例携带上次的纵横比。原图、预览与保存照片分辨率不变；极小细节分析能力可能下降，需真机验收。

紧凑输出 `rows_v1`：`{"s":"摄影环境分析。","p":[[标题,景别,裁切左,裁切上,裁切边长,人物中心x,头顶y,脚底y,人物宽,动作编号,表情编号,强度,朝向,摄影依据,摄影操作],...]}`。每行15项，创建三行、修改一行；所有比例坐标/强度为整数百分数，脚底允许出画。App 只转换坐标单位与字段表示并绑定本次图像 ID，不补造方案或使用固定人体占比。云端仍使用完整 v3；旧离线对象格式仅保留解析兼容。

MNN 构建副本在取消补丁后应用 `mnn-3.6.1-photography.patch`，增加任务作用域内的 token 约束回调。先保留模型原采样；非法 token 从真实 logits 中选最高分合法候选。状态机限定三行完整 JSON、字段顺序、动作/表情能力、画幅裁切/背景保留和人物几何；未完成结构前禁止 EOS、Markdown 与额外字段。坐标按5个百分点量化，朝向5°、表情强度10个百分点量化，仍由模型选择；不将固定候选布局冒充模型分析。为控制解码耗时，生成阶段环境分析最多28字、标题6字、理由/操作各18字；句子以完整标点结束、UTF-8 可跨 token，展示端不截断模型输出。不能由结构约束保证建议美感。

约束器只用于摄影任务，使用真实同次视觉推理；取消、异常、完成时解除回调，其他入口保持原采样。首次摄影建立可复用词表缓存，按首字节分桶；模型释放同时清理。原生采样禁用 speculative 解码以确保状态机与实际输出一致。无需重下载权重；原始 third_party checkout 不改动。只有结构完整且通过完整 v3 业务校验才返回成功。超时或输出预算截断仍失败，不自动第二次推理。

离线优先原样解析合法 JSON，只有不合法时修复结构位置的中文标点，包括英文开引号/中文闭引号混用；正常字符串内中文引号、标点、换行不删除。不补缺失字段、数值或方案。计划数量在旧对象反序列化之前检查，这份日志的一方案/额外字段不会被标点修复提升为三方案成功。

离线摄影的流式停止判断兼容 JSON Markdown 围栏：JSON 本体闭合后即可停止，不等展示用的结束反引号。离线解析也允许完整 JSON 缺少结束围栏；截断 JSON、附加对象、尾部说明及不支持的围栏标签仍拒绝，不补字段或补方案。此规则只作用于本地摄影任务，旧导演和云端包装校验保持原样。格式失败的 Debug 日志记录原文首尾，便于区分包装问题与正文截断。

强制离线摄影整轮最多等待120秒，包含模型排队/加载、首 token、单次生成和 Agent 预览检查；离线不启动第二轮。原生摄影时限也恢复120秒，单次 MNN 摄影入口设同样的协程截止，覆盖自动路由中的本地调用；超时通知算子边界取消，输入文件待原生退出才删除。首 token 后39秒无新输出的保护仍保留。整轮截止报 `LOCAL_PHOTOGRAPHY_DEADLINE`，原生超时报 `LOCAL_NATIVE_TIMEOUT`，停滞报 `LOCAL_TIMEOUT`。未完成 JSON 不作为合法方案显示。截止控制等待时间，不能保证所有导入模型与手机都能在截止前成功输出。


云端新增 `/v3/director/step` 和默认关闭、绑定实际模型的 `directorV3`。旧网关继续 v2/v1 并提示兼容。云端摄影分析正常一步，必要纠正一步，扫描六次调用/12 MiB上传预算仍共享。App 内摄影和尺度字段不进入 v1 序列化。

## 裁切与比例

模型裁切保持照片画幅，跨度下限0.2；跨度小于0.85必须说明摄影理由，背景保护区域至少保留90%。较大裁切允许，但渲染器不得为凑景别另裁背景。数字裁切不等于硬件变焦，应用方案不切镜头。

Filament 根据模型头脚位置、素材标尺和设置身高绘制。AR 固定实体身高，沿脚底射线求与模型头脚目标误差不超过画面5%的站位；可靠地面可升级实测，但不覆盖模型裁切。无地面可建立估算世界锚点，无匹配位置/标尺或失跟时保留屏幕参考。背景距离系数和景别距离先验只留在兼容/区域降级路径，不覆盖有效 VLM 布局。

背景找回使用原图，确认后相机背景、卡片、人像投影与保存照片使用同一裁切。无扫描绑定的单图不等待扫描背景确认。照片不含人偶。手动改站位/动作/表情后停用旧模型指导，显示真实执行步骤。最终规格、缓存与完整渲染回传保留模型目标及估算来源。

## 验证与日志

仅补充测试代码及静态检查，不运行 Gradle、JVM/Android 测试、pytest 或 APK 打包。PhotographyProtocolTest 覆盖协议/数学/有限纠正；设备代码覆盖合成裁切、无地面 GPU 人像及表情；test_photography.py 使用模拟上游。构建和真机验收由用户执行。

日志：`VlmPhotography`（目标与实际布局、裁切理由、比例来源、参照观察），`VlmArScale`（空间求解/失效），导演日志（协议校验/纠正），`VlmOffline`（预填充/输出长度/取消耗时）。不增加逐帧模型调用或日志。

排查离线摄影失败时，保留 `VlmDirector`、`VlmPhotoDiag`、`VlmOffline` 三个标签从任务启动到失败的日志，级别至少 Info。Debug 包中 `VlmPhotoDiag` 分段记录实际用户提示词、完整原始输出、标点/围栏处理后的 JSON 和展开的 v3；每段重复 session/image/request/phase 与 part 编号。模型就绪、分析 JPEG、JNI 入口通过 request 与 input ID 关联；首 token 只记一次，原生结束记录 complete_json/eos/output_limit/native_timeout。`CONSTRAINT_START/VOCABULARY/FINISH` 记录协议、计划数、词表缓存、结构完成状态、过滤次数和约束耗时；不逐 token 输出。最终错误保留失败检查名称、处理阶段、具体原因与原始异常，不再只显示空消息的汇总错误码。Release 包不输出完整提示词/模型文案，仅保留阶段、参数及失败摘要。

用户自测：

1. 门框旁相近深度人物：比例与估算标记。
2. 开阔风景：主体、留白、层次与人物关系。
3. 杂乱背景：高亮、主体遮挡与头部线条重叠的避让。
4. 较大裁切：理由对应照片，确实改善画面，卡片/实时/成片一致。
5. 三套布局：独立摄影依据，不套固定景别模板。
6. 四角色/身高、动作/表情、单方案修改、AR 无地面/失跟/重建及快速取消。
7. 新旧网关声明、换模型后能力失效及预算不重置。
