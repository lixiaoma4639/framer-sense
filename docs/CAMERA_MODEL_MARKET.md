# 摄影视觉模型市场

入口：相机 → 模型设置 → 强制离线／自动切换 → 模型市场。返回市场不会保存或丢弃模型设置草稿。

## 下载与使用

- 市场参考 MNN Chat 官方布局和交互，用 Compose 实现搜索、视觉标签、供应商、参数规模、下载状态筛选及模型详情，不包含聊天或语音页面。
- 展示官方目录所有 `Vision` 条目；开放 Qwen3-VL-2B／4B／8B-Instruct-MNN 及 Gemma 测试候选。Qwen 2B、4B 已由用户验证，8B 用户真机验证未通过，暂保留测试入口。Gemma 固定开放 `gemma-4-E2B-it-MNN`、`gemma-4-E4B-it-MNN`，E2B 用户已验证可用但速度较慢，E4B 待验证；26B／31B 超过现有 12 GiB 安装上限，不开放下载。远程新增 Gemma 不自动加入测试名单。下载、加载成功不代表摄影效果通过验收。
- “已下载”独立展示下载校验成功或导入成功的本地安装，加载、卸载、应用和加载失败不影响归属；进入时清空其他筛选，选择其他筛选或输入搜索时退出。已安装条目不因远程目录缺失而隐藏，卡片采用浅绿色背景；“筛选”位于快捷栏首位，有其他筛选条件时显示选中状态。
- 另开放 `Qwen3.5-2B-MNN`、`Qwen3.5-4B-MNN` 的下载和“用于摄影”入口，均为待真机验证候选。官方 MNN 包默认开启思考，摄影加载时仅在内存配置中设置 `jinja.context.enable_thinking=false`，保留原文件和摘要；沿用现有 CPU、文件校验及 Agent 协议。Qwen3-VL、Gemma、云端参数不变，其他 Qwen3.5 版本不自动开放。
- 下载源独立于云端地域：中文系统首次默认“中国 · 魔搭社区”，其他语言默认“国际 · Hugging Face”，之后记住用户选择。两家使用目录提供的各自仓库 ID 和独立 HTTP 接口。
- HF 固定提交和文件清单；魔搭固定文件清单、每文件版本信息及 SHA-256，不能把清单标识或分支名当作上游不可变提交。上游文件变动导致摘要不符时拒绝安装。
- 多任务可排队，一次只传输一个。暂停保留断点，取消清理该任务的未提交文件；换源只影响新任务。进程重启恢复为暂停，不自动联网。Wi-Fi 默认允许；每次在移动流量下点击下载／继续都弹窗确认，只授权本次请求，不保留后续下载许可。Wi-Fi 下载中切换至未确认的移动流量时暂停，点击继续重新确认。
- 下载校验完成后，在已保存模式为离线／自动、相机前台且空闲时自动加载。背景下载完成后返回相机处理；指定云端不自动加载。多个完成任务以最后完成的模型为待应用对象，也可手动选择“用于摄影”。
- 切换保留其他已下载模型，始终只持有一个原生模型句柄。加载失败时保留原指针及文件，并尝试恢复原先已加载的模型；恢复失败会明确提示。失败候选不会循环自动重试。
- Gemma 4 E2B／E4B 官方包同时声明视觉和音频。摄影加载仅在内存配置中关闭这两个包的音频分支，保留原配置、权重及摘要；仍校验视觉、分词器和 PLE 嵌入文件，不启用语音功能。此前因音频标记校验失败的完整下载可点击“继续”复用文件重新校验，无需删除重下。通过目录校验仍需真机验证推理效果。
- 删除需要确认，当前模型先卸载；其他模型不受影响。文件夹／ZIP 导入及手动加载、卸载仍保留；已登记的本地导入视觉模型也能在市场管理。

## 来源和数据

官方参考：[MNN Chat](https://github.com/alibaba/MNN/tree/master/apps/Android/MnnLlmChat)、[官方模型目录](https://github.com/alibaba/MNN/blob/master/apps/Android/MnnLlmChat/app/src/main/assets/model_market.json)、[官方下载框架](https://github.com/alibaba/MNN/tree/master/apps/frameworks/model_downloader/android)。

内置视觉目录及 Apache-2.0 许可位于模块 `src/main/assets/model-market/`，来源提交和目录版本见 `SOURCE.txt`。官方远程目录优先与内置/缓存版本比较，刷新失败继续显示本地数据；远程新增条目不能扩大摄影兼容名单。

旧安装和 `vlm-download.json` 原地登记，无需搬移或重新下载。安装索引仍使用原私有设置仓库；不同模型的断点和市场队列独立持久化。QWEN／Seed Key、云端配置、MNN JNI 推理协议及取消机制不变。

## 本地验收

本轮仅补充测试代码和静态检查，没有运行 Gradle／Android 测试、真实下载或 JNI 推理。

1. 先复验原离线 2B、QWEN 和 Seed 构图流程。
2. 在市场往返，确认设置草稿保留；检查搜索筛选、模型详情、暂不支持条目的下载禁用。
3. 分别使用魔搭和 HF 下载，检查暂停／继续、取消当前任务后队列继续，以及进程终止后暂停恢复；旧 HF 断点切换市场源后仍使用原来源。
4. 在构图忙碌／相机后台／指定云端时完成下载，确认不抢占加载；返回离线相机后自动应用，切换失败不重复尝试。
5. 检查模型切换保留原文件，删除当前模型先卸载且不影响其他安装。Gemma 的加载、内存、速度、单图和多图摄影效果单独验证；本次只开放入口，不放宽视觉目录校验或修改 MNN 推理协议。

日志：`VlmOffline` 的下载完成包含实际模型、来源和 `inferenceVerified=false`；模型切换记录成功、失败及原模型恢复结果，推理日志继续记录实际模型。
